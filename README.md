## 📘 Description
**RobotFactory** est le compilateur assembleur du projet Corewar. Il prend en entrée des fichiers source assembleur (`.s`) décrivant le comportement des champions et produit les binaires exécutables (`.cor`) encodés en bytecode pour l'arène virtuelle.

## 🔨 Compilation & Utilisation
```bash
make
./asm champion.s
```
